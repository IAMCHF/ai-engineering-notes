### 项目经历

#### 1. AI 编程助手（Agent 平台）+ 建站 MCP ｜ 图编排与前端负责人，MCP 独立负责 ｜ 2025.10 – 2026.11

**项目背景**：企业内网 AI 编程助手。团队已有 Agent 平台基础框架（模型接入、会话服务），我负责图编排层、流式对话前端、Langfuse 与评测；降级与排障与同事共同实现。建站 MCP 作为附加工具链，由我独立负责。

**技术栈**：Python、FastAPI、LangGraph、SSE、React + TypeScript、IndexedDB、Langfuse、MCP SDK、Redis

- **图编排（负责）**：在既有 Agent 框架上实现意图识别 → 计划 → 工具执行 → 反思/重规划 → 降级分支的图编排，定义状态流转、重规划触发与终止条件，打通工具调用链路；与同事共同实现主备模型降级与错误分类。
- **流式对话前端（负责）**：基于 fetch + ReadableStream 手写 SSE 解析，处理 TCP 分片与 UTF-8 多字节边界、推理模型思维链标签跨 chunk 截断；用 ref/state 分工解决多对话并行时的状态污染，IndexedDB 作为会话单一数据源。
- **Langfuse 与评测（搭建）**：搭建节点级 trace，覆盖编排、工具调用与降级链路，支持失败链路回放；建立评测用例集与指标（任务成功率、步数、token 成本、P95），用于编排策略迭代。
- **排障复盘（与同事协作）**：针对主模型超时、工具返回语义错误等故障，基于 trace 定位到具体节点，按「现象 → 证据 → 根因 → 修复 → 复测」形成复盘。
- **MCP 建站（独立负责）**：基于官方 MCP SDK 实现 22 个工具与六阶段部署状态机，打通建站、部署、入口申请、状态核验；核心 4.9k 行 / 19 模块 / 20 个测试。
- **确认安全（MCP）**：把用户确认从 MCP 工具中物理移除——plan 只返回本地回环 confirmation_url，approve 仅由本地 UI 的 HTTP 端点调用，execute 强校验 approval_digest；配合单窗 20s / 总预算 120s 的有界等待与 wait_expired 显式交接。

#### 2. 模型广场 + 技能广场 ｜ 前端负责人 / 模型部署与平台调优 ｜ 2025.11 – 2026.10

**项目背景**：企业内网 AI 资源平台。模型广场管理 API 服务与大模型，技能广场负责 Agent 技能的发布、审核与分发。后端基于团队既有 RuoYi-FastAPI + Kong 架构，由后端同事搭建；我负责前端、模型接入部署、技能筛选与安全审核，后端同事离职后接手性能调优。

**技术栈**：React 18 + TypeScript + Ant Design + Vite、FastAPI、Kong、MySQL、Redis、Docker

- **前端（负责）**：负责模型广场与技能广场前端，覆盖模型申请、技能发布与版本管理、批量上传、权限控制；技能广场前端 156 commits 主负责，约 2 万行 TS。
- **模型接入与部署（负责）**：参与 500+ 模型的接入与部署，把配置生成、服务注册、网关路由、健康检查沉淀为可复用 Skill，批量完成上线，减少重复手工操作。
- **技能筛选与安全审核（负责）**：负责技能筛选与安全审核，落地规则校验 + LLM 评审，独立实现评审服务（1.7k 行），控制技能准入质量。
- **性能调优（后端同事离职后接手）**：围绕多进程部署、数据库连接池与慢查询定位瓶颈；压测发现连接池上限与数据库最大连接数不匹配，输出扩容与参数调整方案。

#### 3. PPT 检索与生成服务 ｜ 检索评测与调优 / 生成侧 Demo ｜ 2026.04 – 2026.08

**项目背景**：企业门户内的 PPT 大纲生成工具。检索服务框架、知识库接入与跨部门数据由团队同事搭建；我负责服务后续的检索评测与调优，并基于现有服务搭建生成侧 Demo。

**技术栈**：Python、FastAPI、RAGFlow、Qwen、PostgreSQL、React + TypeScript

- **检索评测（负责）**：构建评测集与指标（Recall@5、MRR、P50/P95），按 query 类型分析 badcase，定位召回噪声与排序问题，输出检索参数与过滤策略的调优建议。
- **服务调优（负责）**：拆分 embed / search / rerank 各段耗时，围绕 top-k、分数阈值与 rerank 策略做调优，兼顾召回质量与响应延迟。
- **生成侧 Demo（负责）**：基于现有检索服务搭建大纲生成 Demo，输出带引用的大纲，要点可回溯原文片段、相似度与源文件；对空召回与低分命中做显式失败提示，避免 LLM 编造。
