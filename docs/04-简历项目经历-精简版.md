### 3. PPT 检索与生成 ｜ 评测调优 / 生成实现 ｜ 2026.04 – 2026.08

**定位**：面向内部 PPT 生产的检索与生成服务，负责检索评测调优与生成侧链路；RAGFlow + 企业 LLM 网关。

**边界**：检索服务与跨部门数据由同事搭建；我负责后续评测调优与生成链路。

**技术栈**：RAGFlow、企业 LLM 网关、PostgreSQL、Docker

- **检索评测（负责）**：构建评测集，以 Recall@5、MRR、P50/P95 为核心指标；按 query 类型分析 badcase，输出 top-k、阈值与 rerank 调优建议，避免单一平均指标掩盖长尾失败。
- **生成链路（负责）**：搭建并跑通主题 → 检索 → 带引用大纲的完整链路；要点可回溯原文片段与源文件，空召回时显式失败，避免 LLM 编造。
- **服务调优（负责）**：拆分 embed、search、rerank 三段耗时，围绕召回质量与响应延迟做参数调优，定位瓶颈段。
